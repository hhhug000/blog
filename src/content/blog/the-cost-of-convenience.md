There was once a time where using a computer required active participation. To make a computer do what you wanted, you had to understand how it worked (to an extent). If you wanted to install a program, or write a document, you had to know how to use a file system, what a folder is, how to find the software on the internet.

Today this is not the case, tablets and phones can write notes just by opening the notes app, and finding software online is a task of the past, now you can simply open an app store, and search for what you want. You don't have to mess with your phone's settings, or install drivers, you turn it on, and it just works.

At first, this seems perfect, why would anyone want to go back to having to debug your computer to play a game when you can just press download and then play in an app store? But this all comes at a cost, we have traded deep control and technical literacy for convenience. Modern software is built around the fact that the user should never have to see under the hood. Everything is abstracted away, removing the necessity, and as such the opportunity, to see how it works.

**File Management**

On a desktop computer files are organised into folders, and files can have types, for example this blog post is being written in markdown, so its called `costofconvenience.md` file, I know where this file is on my computer, and I can always trace my steps through my folders to find it. But if I wrote this on an iPad, I would not have any of this, I would open a text editor, and get a list of my recent documents, I wouldn't know where the file was, it would be in a hidden inaccessible folder just for that app, or maybe even in the cloud, sitting in a datacenter somewhere. This makes file management simpler, but also restricts our choices. If I decide that I don't like MarkText anymore, I could use marker, or KWrite. But on black box file systems, I am stuck with my choice, I cant just move from Apple Notes to a competitor, sure I could copy and paste all my writing over, but if I have hundreds of files, this will take forever. On traditional computers I just open the file in another program, no questions asked.

**Losing our skill**

The consequences of this oversimplification of technology, apart from being locked into walled gardens, and black boxes, is that we lose our skill to use these tools ourselves. A tablet user has never had to mount a network drive or fix file permissions, so why should they know how? This is fine if you stay in the walled garden, but eventually some people will have to leave. Your skill is like a muscle, you need to use it or lose it. If you never need to fix anything, you'll never be able to solve any problems.
